# C++ 学习代码整理

C++ 基础语法与面向对象的学习代码，按知识点分大类整理。每个子目录都是一个独立的 Visual Studio 工程，可单独打开、编译、运行。

## 目录总览

| 大类 | 示例数 | 主要内容 |
| --- | --- | --- |
| **01-C++基础** | 9 | HelloWorld 与命名空间、整型/浮点型/字符/字符串/布尔类型、数据输入 |
| **02-运算符与表达式** | 13 | 算术、取余、自增自减、赋值、比较、逻辑、逗号、位运算（与/或/异或/取反/左右移） |
| **03-流程控制** | 10 | if / if-else / else-if / 三目 / switch、while / do-while / for、break / continue |
| **04-数组** | 2 | 一维数组、二维数组 |
| **05-函数** | 4 | 函数的定义、声明、形参与实参、非安全函数 |
| **06-指针** | 14 | 地址与解引用、空指针与野指针、const 与指针、指针与数组、数组指针、指针数组、指针传参、指针函数、函数指针与函数指针数组 |
| **07-结构体与联合体** | 8 | 结构体定义/数组/指针/嵌套/传参、联合体、内存对齐与大小端、union 应用 |
| **08-内存分区** | 6 | 代码区、全局区、栈区、堆区、new/delete 内存申请与释放 |
| **09-引用** | 7 | 引用的语法/特性/本质、引用作参数、引用作返回值、常量引用、指针引用 |
| **10-类与对象** | 9 | 封装与访问权限、class 与 struct 区别、构造函数、析构函数、拷贝构造、初始化列表、静态成员 |
| **11-综合项目** | 1 | 贪吃蛇（纯 C 语言实现）等综合练习 |

合计 **83** 个示例工程。

## 说明

- 每个子目录是独立的 VS 工程（`.slnx` + `.vcxproj`），双击 `.slnx` 即可用 Visual Studio 打开运行。
- 源码已统一为 **UTF-8 (带 BOM)** 编码，Windows 下 VS 与 GitHub 网页都能正确显示中文注释。
- 编译产物（`.vs`、`x64/`、`*.obj`、`*.exe`、`*.pdb`、`*.tlog` 等）已通过 `.gitignore` 排除，仓库只保留源码与工程配置。
- 目录名前的数字是原来的章节编号，方便和课件对应。
- 综合项目的「贪吃蛇」是 C 语言（`.c`/`.h`），其余均为 C++。
